Rules

  • IDs. Leave out "id" (or write "NEW-1", "NEW-2") on new items and highlights; the server assigns them. IDs never change, and a deleted ID is never reused.
  • Evidence. skills[].evidenceIds lists the highlights that prove a skill. A "NEW-n" placeholder works within the same save.
  • Dates. YYYY-MM. For a current role, use "endDate": null or leave it out.
  • Phone. E.164, e.g. +6591234567.
  • Never stored (P6). NRIC/FIN, date of birth, age, photo, gender, race, religion, marital status, children, residential address, salary, referees.
  • Server-owned. meta.version and meta.updatedAt are set on every save.
